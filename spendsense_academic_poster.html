I.

Abstract

IEEE Research Summary

The rapid proliferation of digital payment systems in India, particularly the Unified Payments Interface (UPI), has fragmented individual financial activity across six to eight applications simultaneously, including UPI wallets, credit cards, BNPL platforms, and recurring subscriptions. Empirical studies indicate that ~75% of Indian UPI users report increased overspending attributable to cashless intangibility. SpendSense is a Flutter-based mobile platform that automatically ingests transaction data from bank and UPI SMS notifications on-device, without requiring account linking, password sharing, or cloud connectivity.

Execution Target 100% On-Device (ARM64)
Forward Latency 0.89 ms (TFLite MTL)
Network Exposure Zero Telemetry Packets
Model Footprint 1.04 MB (0.29 MB INT8)

A single multi-task TensorFlow Lite model simultaneously predicts merchant identity (99.86%), 15 canonical spending categories (96.76%), and payment mode in a single forward pass, coupled with proactive 80% solvency guardrails. SpendSense demonstrates that an offline-first edge architecture delivers intelligent, India-specific financial insights at zero recurring infrastructure cost.

Index Terms: Personal Finance Management, UPI, Transaction Categorisation, Multi-Task Learning, On-Device Machine Learning, TensorFlow Lite, SMS Parsing, Flutter, Privacy-Preserving Computing.

VII.

Conclusion & Impact

Scientific Takeaways

SpendSense demonstrates that an autonomous, offline-first personal financial framework delivers state-of-the-art telemetry and proactive behavioral guidance in India's high-velocity UPI ecosystem. It eliminates the privacy risks and credential scraping inherent to cloud PFM platforms while operating at zero recurring server cost.

Key Architectural & Behavioral Contributions
• Zero-Cloud Telemetry: 100% on-device SQLite persistence protects credentials and transaction logs from server scraping.
• Sub-Millisecond Multi-Task ML: Predicts merchant identity and canonical category in 0.89 ms via a compressed 1.04 MB model.
• Proactive Solvency Alerts: Intercepts category budget depletion at 80% threshold, mitigating cashless intangibility bias.
• Zero Recurring Cost: Entire inference and deterministic NLG run locally with zero server hosting or LLM token overhead.
Future Edge Research Roadmap
• Federated Learning: Decentralized FedAvg updates across client nodes without centralizing raw telemetry.
• Cross-Border UPI: Multi-currency localized parsing for Singapore PayNow, UAE, and European corridors.

By pairing deterministic regex ingestion with a compact multi-task neural network, edge computing protects consumer solvency at zero infrastructure cost.
